# PySmartKit 🐍

**PySmartKit** is a simple and reusable Python module that provides useful mathematical and utility functions for students and developers.

## ✨ Features

This module provides the following 12 functions:

1. `add(a, b)` – Adds two numbers.
2. `square(n)` – Calculates the square of a number.
3. `is_even(n)` – Checks whether a number is even.
4. `factorial(n)` – Calculates the factorial of a non-negative integer.
5. `subtract(a, b)` – Subtracts two numbers.
6. `multiply(a, b)` – Multiplies two numbers.
7. `divide(a, b)` – Divides two numbers.
8. `largest(a, b, c)` – Finds the largest of three numbers.
9. `is_prime(n)` – Checks whether a number is prime.
10. `celsius_to_fahrenheit(c)` – Converts Celsius to Fahrenheit.
11. `cube(n)` – Calculates the cube of a number.
12. `reverse_string(text)` – Reverses a string.

## 🚀 How to Use

Make sure Python is installed on your computer.

### 1. Import the module

Keep `pysmartkit.py` in the same folder as your Python program.

```python
import pysmartkit
```

### 2. Use the functions

```python
import pysmartkit

print(pysmartkit.add(10, 20))
print(pysmartkit.square(5))
print(pysmartkit.is_even(8))
print(pysmartkit.factorial(5))
print(pysmartkit.is_prime(7))
print(pysmartkit.reverse_string("Python"))
```

### Output

```text
30
25
True
120
True
nohtyP
```

The purpose of PySmartKit is to make common programming tasks easier by providing reusable functions that can be imported into different Python programs.
